# BinixX OS Documentation

Welcome to the English documentation for BinixX OS, a Fedora-based Linux desktop designed to feel familiar to Windows users.

> **Project status:** BinixX OS is actively developed. Compatibility information reflects current project documentation and virtual-machine tests; it is not a guarantee of support on every physical computer.

When reporting a problem, include the BinixX OS version, relevant hardware details, steps to reproduce the issue, and error messages. Review logs and diagnostic reports before posting. Never publish passwords, disk recovery keys, private documents, or other sensitive data.

## Important notes

- Installing an operating system may erase the selected disk. Back up important files first.
- Windows applications do not run natively. Check compatibility before replacing Windows.
- Hardware support depends on Linux drivers, firmware, and device-specific behavior.
- Third-party components remain subject to their own licenses and privacy policies.
