# Security Policy

## Supported versions

Only the release published under the `stable` tag (`ghcr.io/nic69han/binixx:stable`) receives security fixes. Installed systems following this channel update automatically.

## Reporting a vulnerability

Please **do not** open a public issue for a security vulnerability.

Use GitHub's private vulnerability reporting feature: open the repository's **Security** tab and select **Report a vulnerability**. Include:

- the affected version (run `bootc status` on the affected system);
- steps to reproduce the issue;
- its potential impact, such as data access, privilege escalation, or code execution.

The project aims to acknowledge reports within seven days and publish a fix as soon as practical. Vulnerabilities in Fedora or Universal Blue components should be reported to the relevant upstream project.

Reports in either English or French are welcome.

Do not include passwords, disk recovery keys, personal documents, or unrelated sensitive information in the report.
