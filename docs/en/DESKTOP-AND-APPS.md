# Desktop and Applications

BinixX OS uses KDE Plasma with a Windows-inspired layout. The interface is customized, but the underlying applications remain Linux and KDE applications.

## Desktop basics

- Open the application menu from the BinixX OS button or press the Windows key.
- Use the taskbar to switch between open applications and pin frequently used applications.
- Open **System Settings** to configure displays, network, Bluetooth, sound, keyboard, appearance, and other options.
- The global themes **BinixX OS** (light) and **BinixX OS dark** (dark) provide matching desktop colors. Options may vary by release.
- Press **Windows + E** to open Dolphin, the file manager.

The taskbar is placed at the top by default. KDE Plasma allows the panel to be repositioned using its panel configuration options.

## File management with Dolphin

Dolphin is the default file manager. The BinixX OS layout uses a compact toolbar and large file icons.

| Shortcut | Action |
| --- | --- |
| Windows + E | Open the file manager |
| Ctrl + F | Search |
| Ctrl + X / Ctrl + C / Ctrl + V | Cut / copy / paste |
| F2 | Rename the selected item |
| Delete | Move the selected item to the Trash |
| F9 | Show or hide the Places panel |

Right-click files or empty space for actions such as copy, paste, rename, create a folder, or sort items. Hidden files can be enabled through view settings. Dolphin can access supported network shares, removable devices, archives, and the Trash.

## Install applications

Use KDE Discover to browse and install supported applications, including applications delivered through Flathub. Availability varies by application and release.

Prefer official Linux versions or trusted repositories. Do not run arbitrary installation scripts or commands copied from unknown sources. Windows installers (.exe and .msi) are not native Linux packages.

| Need | Application or approach |
| --- | --- |

| Email | Thunderbird |
| Office documents | OnlyOffice |
| PDF reading and annotation | Okular |

Compatibility depends on your files, account type, and workflow. Test complex office documents, macros, specialist software, printers, and work-related tools before replacing Windows.

## Privacy-conscious use

The operating system's diagnostic report is generated locally according to the project documentation, but third-party applications may connect to their own services. Review application permissions and privacy policies, and inspect logs before sharing them.

For recovery, updates, and security settings, see [Updates and Recovery](UPDATES-AND-RECOVERY.md) and [Security and Privacy](SECURITY-AND-PRIVACY.md).
