# Politique de sécurité

## Versions prises en charge

Seule la version publiée sous l'étiquette `stable` (`ghcr.io/nic69han/binixx:stable`) reçoit des
correctifs. Les postes installés la suivent et se mettent à jour automatiquement.

## Signaler une faille

Merci de **ne pas** ouvrir d'issue publique pour une faille de sécurité.

Utilisez le signalement privé de GitHub : onglet **Security** du dépôt, puis
**Report a vulnerability**. Indiquez :

- la version concernée (`bootc status` sur le poste) ;
- comment reproduire le problème ;
- son impact (accès aux données, élévation de privilèges, exécution de code…).

Nous accusons réception sous 7 jours et publions un correctif dès que possible. Une faille dans un
composant de Fedora ou d'Universal Blue est remontée au projet concerné.

Les signalements en français ou en anglais sont les bienvenus.
